# NeoSphere User Flow

## Вход

Пользователь отвечает на вопрос:

"Что сейчас мешает?"

---

## Варианты

1. Перегруз, шум, напряжение  
→ Reset

2. Много мыслей, нет структуры  
→ Architect 01

3. Не могу выбрать  
→ Architect 02

4. Не могу сосредоточиться  
→ Architect 03

5. Нужно действовать, но мешают эмоции  
→ Architect 04

---

## Логика

Каждый выбор ведёт к соответствующей сессии.

---

## Расширение

После прохождения пользователь может:

- перейти к следующему этапу
- повторить сессию
- сменить режим

---
