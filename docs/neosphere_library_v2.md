# NeoSphere Library v2

## Статус

Расширенная рабочая библиотека аудиовизуальных сессий NeoSphere.

---

## Структура библиотеки

NeoSphere состоит из трёх основных модулей:

1. Reset — обнуление
2. Architect — структура и действие
3. Dream — сон

---
