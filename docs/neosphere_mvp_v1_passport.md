# NeoSphere MVP v1.0

## Статус

Рабочий MVP продукта.

## Концепция

NeoSphere — система управления состоянием через последовательные аудиовизуальные протоколы.

## Три ступени продукта

1. Reset — обнуление
2. Architect — структура
3. Dream — сон

## Полный протокол

Reset 01  
→ Architect 01 — Structure  
→ Architect 02 — Select  
→ Architect 03 — Focus  
→ Architect 04 — Cold Mode  
→ Dream 01 — Продавец снов

Пользователь выбирает формат работы.  
Система показывает сессию, собирает обратную связь и ведёт к следующему шагу.
