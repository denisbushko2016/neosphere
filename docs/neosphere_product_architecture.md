# NeoSphere Product Architecture v2

## Общая концепция

NeoSphere — это система управления психическим состоянием через последовательные аудиовизуальные протоколы.

Продукт построен как управляемая среда перехода состояний:

```text
состояние → воздействие → изменение → фиксация → следующий шаг
Архитектура системы

NeoSphere состоит из трёх модулей:
Reset → Architect → Dream
1. Reset

Назначение

Снижение внутреннего шума, перегрузки и напряжения.
Подготовка системы к дальнейшей работе.

Сессии

Reset 01 — Мягкое обнуление

* мягкий вход
* снижение активности
* подготовка

Reset 02 — Глубокое обнуление

* выраженное снижение перегрузки
* эффект втягивания
* концентрация внимания

Reset 03 — Восстановительное обнуление

* расслабление
* восстановление
* мягкое снижение активности

⸻

2. Architect

Назначение

Переход от хаоса к действию через структурирование мышления.

Логика
Structure → Select → Focus → Cold → Action
Сессии

Architect 01 — Structure

* структурирование мыслей

Architect 02 — Select

* выделение главного

Architect 03 — Focus

* удержание внимания

Architect 04 — Cold Mode

* снижение эмоционального шума
* холодная ясность

Architect 05 — Action

* запуск действия
* формирование импульса

⸻

3. Dream

Назначение

Переход в сон, углубление и стабилизация.

Логика
Вход → Углубление → Стабилизация
Сессии

Dream 01 — Вход в сон

* появление образного поля

Dream 02 — Углубление сна

* снижение активности
* усиление сонного состояния

Dream 03 — Стабилизация сна

* удержание сна
* снижение внешней реакции

⸻
