# NeoSphere MVP v1.1

## Статус

Рабочая версия MVP с адаптивной логикой и журналом прохождения.

## Что реализовано

- выбор текущего состояния пользователя
- подбор протокола
- запуск аудиовизуальных сессий
- обратная связь после каждой сессии
- адаптивная логика переходов
- повтор сессии при отсутствии эффекта
- возврат к Reset при дискомфорте
- журнал прохождения в CSV

## Основные протоколы

### Полный цикл NeoSphere

Reset 01  
→ Architect 01 — Structure  
→ Architect 02 — Select  
→ Architect 03 — Focus  
→ Architect 04 — Cold Mode  
→ Dream 01 — Продавец снов

### Быстрые сценарии

- Перегруз и внутренний шум
- Мысли разбросаны
- Не могу выбрать главное
- Не могу сосредоточиться
- Нужно действовать, но мешают эмоции
- Не могу отключиться и уснуть

## Адаптивная логика

Положительный результат:
- переход к следующему шагу

Нейтральный результат:
- повтор текущей сессии один раз

Дискомфорт:
- возврат к Reset или остановка протокола
