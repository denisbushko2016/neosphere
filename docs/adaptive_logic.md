# NeoSphere Adaptive Logic

## Назначение

Адаптивная логика превращает NeoSphere из линейного плеера сессий в систему, которая реагирует на состояние пользователя после каждого этапа.

## Базовый цикл

```text
состояние → сессия → обратная связь → решение системы

Варианты обратной связи

Положительный эффект

Примеры:

* Стало спокойнее
* Появилась структура
* Удалось выбрать главное
* Фокус усилился
* Появилась холодная ясность
* Появилась сонливость / расслабление

Решение системы:перейти к следующему шагу

Нейтральный эффект

Пример:

* Не почувствовал изменений

Решение системы:повторить текущую сессию один раз

Если повтор уже был:перейти к следующему шагу

Негативный эффект

Пример:* Появился дискомфорт
Решение системы:вернуться к Reset или остановить протокол

Текущий статус

Адаптивная логика реализована в:interface/app.py

Следующий этап развития

* расширить варианты обратной связи
* добавить персональные маршруты
* добавить журнал прохождения
* добавить сохранение результатов
